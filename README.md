### Featured Projects

* **[Chatty](https://github.com/PersonaliAI/chatty)** — Open-source AI customer support platform with real-time voice (LiveKit), document RAG, conversational meeting booking (Google Meet & Zoom), and live human takeover.
* **[Kin](https://github.com/PersonaliAI/kin)** — Autonomous personal AI assistant managing email, calendar, and daily tasks through natural conversation.
* **[AI Voice Agents](https://github.com/PersonaliAI/ai-voice-agents)** — Real-time WebRTC audio worker bridging live calls over Telegram and WhatsApp.

### Integration SDKs

Drop-in support chat with 100% web widget parity and native UI:

* 🌐 **Web**: `<script src="https://chatty.personaliai.com/widget.js" data-id="YOUR_BOT_ID" defer></script>`
* ⚛️ **React Native**: [`@personaliai/react-native`](https://github.com/PersonaliAI/chatty-react-native-sdk)
* 💙 **Flutter**: [`chatty_flutter`](https://github.com/PersonaliAI/chatty-flutter-sdk)
* 🤖 **Android**: [`chatty-android-sdk`](https://github.com/PersonaliAI/chatty-android-sdk) (Kotlin + Jetpack Compose)
* 🍎 **iOS**: [`chatty-ios-sdk`](https://github.com/PersonaliAI/chatty-ios-sdk) (SwiftUI)
* 🔌 **WordPress**: [`chatty-wordpress-plugin`](https://github.com/PersonaliAI/chatty-wordpress-plugin)
